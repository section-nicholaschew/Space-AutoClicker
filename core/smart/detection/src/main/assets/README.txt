Tesseract OCR Language Files

This directory should contain the Tesseract language data files in zip format.
Download the English language data file ("eng.traineddata") from:
https://github.com/tesseract-ocr/tessdata/raw/main/eng.traineddata

Then create a zip file with this single file inside, naming it "eng.traineddata.zip".

For other languages, download the appropriate language file from:
https://github.com/tesseract-ocr/tessdata/

The OCR detection will only work properly when these language files are available.
